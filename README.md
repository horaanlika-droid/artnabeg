# АРТНАБЕГ

**Telegram Mini App — NFT-галерея и маркетплейс независимых художников.**
Искусство вне стен. Теперь on-chain.

- 🖼 NFT-работы (TON / грам) и физическое искусство
- 🛡 Гаранта: по физическим работам площадка **замораживает средства** до подтверждения доставки
- 💸 Комиссия площадки — **8%** с продажи (NFT и физика)
- ⏳ Выложить работу можно **только через модерацию**
- 🛠 Админка: модерация, сделки, статистика — в мини-аппе + через бота
- 💬 Поддержка: юзер пишет в мини-аппе, **админ отвечает через бота** (reply или `/re ID текст`)
- 🔗 Кошелёк (грам) привязывается через **TON API (tonapi.io)** — подтверждение переводом с код-фразой или подписью

---

## Стек

Node.js 18+ · Express · grammY (бот) · better-sqlite3 (файл `data/artnabeg.db`) · ванильный JS-фронт (без сборки).

```
src/
  index.js     — точка входа (сервер + бот)
  server.js    — Express API + статика
  bot.js       — бот: меню, заказы, поддержка, админ-команды
  db.js        — SQLite-схема и запросы
  ton.js       — TON API (tonapi.io): курс, кошелёк, верификация
  payments.js  — приём оплат в TON (Crypto Pay API) + демо-режим
  seed.js      — демо-контент (работы из репо)
public/
  index.html   — лендинг (домен / BotHost)
  app.html     — мини-апп (Telegram)
uploads/       — загруженные работы (не в git)
```

## Быстрый старт

```bash
npm install
npm run seed     # демо-работы + художники
npm start        # http://localhost:3000 (лендинг /, мини-апп /app)
```

Без токена бота сайт работает, бот просто выключен. Есть демо-вход и демо-оплата (`ALLOW_DEMO=1`).

## Переменные окружения

Скопируй `.env.example` → `.env` и заполни:

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID` | твой Telegram ID (узнать у @userinfobot). Этому юзеру доступны админка и ответы в поддержке |
| `PUBLIC_URL` | **https**-адрес сайта (напр. `https://artnabeg.bot.host`) — для кнопки мини-аппа в боте |
| `TON_API_BASE` | по умолчанию `https://tonapi.io` (TON API) |
| `TON_API_KEY` | ключ tonapi.io — бесплатный, выдаёт [@tonapibot](https://t.me/tonapibot) |
| `TREASURY_ADDRESS` | твой TON-адрес площадки: сюда идут оплаты и переводы для подтверждения кошельков |
| `CRYPTO_BOT_TOKEN` | *(опционально)* токен [@CryptoBot](https://t.me/CryptoBot) → Crypto Pay API — приём оплат в TON. Пусто = демо-оплата |
| `SESSION_SECRET` | случайная строка для подписи cookie |
| `ALLOW_DEMO` | `0` в проде — выключает демо-вход и демо-оплату |
| `PORT` | порт, по умолчанию 3000 |

## Настройка бота

1. [@BotFather](https://t.me/BotFather) → `/newbot` → токен в `BOT_TOKEN`.
2. BotFather → `/setmenubutton` → выбери бота → URL: `https://ТВОЙ_ДОМЕН/app` → название «Открыть АРТНАБЕГ».
3. BotFather → `/newapp` (опционально, для ссылки-кнопки): тот же URL, загрузи картинку 640×360.
4. Запусти: `npm start`. Бот поднимает long polling сам, вебхуки не нужны.
5. Зайди в бота под аккаунтом с `ADMIN_ID` — увидишь админ-меню.

## Как работает сделка

**NFT (цифровая работа):**
оплата → NFT закрепляется за покупателем (токен `ANB-XXXX/NNNN` в базе, сеть TON) → продавцу сразу начисляется выплата −8%.

**Физическая работа (гарант):**
оплата → 💰 **средства заморожены в гаранте площадки** → продавец отправляет работу и указывает трек → покупатель подтверждает получение → выплата продавцу −8%. Если спор — админ в админке завершает сделку вручную («Завершить» / «Возврат»).

Комиссия считается так: с 1 TON площадка берёт 0.08 TON, продавцу уходит 0.92 TON (видно в карточке заказа и в сводке админа).

## Привязка кошелька (грам через API)

Профиль → Кошелёк → вводишь TON-адрес → площадка выдаёт **код-фразу** → подтверждаешь одним из способов:
- отправляешь **любой перевод** на `TREASURY_ADDRESS` с код-фразой в комментарии — сервер найдёт транзакцию через tonapi.io и привяжет кошелёк;
- либо подписью сообщения (если кошелёк умеет).

Статус и баланс кошелька подтягиваются из tonapi.io (`TON_API_KEY` обязателен для стабильных лимитов).

## Поддержка

- Юзер: мини-апп → Поддержка → пишет сообщение.
- Админ получает сообщение в бота: **reply на него = ответ юзеру** (текст или фото), либо `/re ID текст`.
- Ответ приходит юзеру и в бот, и в чат поддержки мини-аппа.

## Деплой на BotHost

```bash
git clone <репо> && cd artnabeg
npm install
cp .env.example .env   # заполнить
npm run seed           # опционально
npm start              # или pm2 start src/index.js --name artnabeg
```

- Открой порт 3000 (или свой `PORT`) и повесь https-домен — Telegram Mini App требует **https**.
- В BotHost укажи домен лендинга на этот порт: `/` — лендинг, `/app` — мини-апп.
- `PUBLIC_URL=https://домен` в `.env`, потом перезапусти.
- База (`data/`) и загрузки (`uploads/`) живут рядом с проектом — настрой бэкап.

## Админ-команды бота

| Команда | Действие |
|---|---|
| `/admin` | панель админа (кнопки) |
| `/tickets` | открытые тикеты поддержки |
| `/re ID текст` | ответ в тикет |
| reply «Тикет #N» | ответ/фото в тикет |

В мини-аппе (`/#/admin`): модерация работ (✓/✕ с причиной), сделки (завершить гаранта / возврат), тикеты, сводка (оборот, комиссия, заморожено в гаранте).
